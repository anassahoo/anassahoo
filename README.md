## 🛰️ Current Research

### GlacioSentinel — AI-Driven Glacial Lake Monitoring

**Research focus:** Deep Learning · Remote Sensing · GeoAI · Environmental Monitoring

My Final Year Project investigates the application of artificial intelligence and satellite remote sensing for monitoring glacial lakes in northern Pakistan.

**Research components:**

- Sentinel-2 satellite imagery acquisition and preprocessing
- NDWI-based water body extraction
- U-Net-based glacial lake segmentation
- Lake boundary delineation
- Temporal lake surface-area analysis
- Geospatial visualization using WebGIS
- Exploration of applications in GLOF monitoring

**Technologies:** Python · PyTorch · U-Net · Sentinel-2 · NDWI · FastAPI · PostgreSQL · PostGIS
